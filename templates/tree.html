Tree

Interactive folder/tree component with state persistence

Lightweight tree view with lazy-loading hooks, context menu, and automatic state persistence across refreshes.

Installation

Include the core and tree packages in your HTML:

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">
<link rel="stylesheet" href="../packages/tree/dist/tree.css">

<!-- Scripts -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/tree/dist/tree.min.js"></script>
Quick Start
// Define your tree data structure
const treeData = [
  { 
    name: 'Documents', 
    children: [ 
      { name: 'Resumé', children: [] },
      { name: 'Cover Letter', children: [] }
    ] 
  },
  { 
    name: 'Projects', 
    children: [ 
      { name: 'Website', children: [] },
      { name: 'App', children: [] }
    ] 
  }
];

// Create the tree component
const tree = new uiframe.Tree({ 
  name: 'my-tree', 
  objects: treeData 
});

// Render into a container
tree.renderInto('my-tree-container');
Options
  • objects: Initial JSON tree array with {name, children} nodes.
  • data_callback: Optionally supply a callback to load children lazily.
  • contextData: Array of context menu items.
API
  • renderInto(id): Renders the component into a container element.
  • update(node, data): Appends new children to a node.
  • refresh(node, data): Replaces children of a node with new data.
  • remove(node): Removes a node from the tree.
Features
  • State Persistence: Expanded nodes stay expanded even if you refresh the tree (as long as names/structure remain consistent).
  • Lazy Loading: Use data_callback to fetch children on expand.
  • Context Menu: Built-in configurable context menu with custom callbacks.
  • Dynamic updates: Add, refresh, or remove nodes at runtime.
  • Automatic IDs: Node IDs are generated from path for consistent state management.
Features
  • Node structure: Each node requires { name, children } properties; children is always an array.
  • ID generation: IDs are derived from node names for persistence; ensure unique names within parent.
  • Context menu items: Can include a callback(context, node) function for custom actions.
  • Lazy loading: Return children array from data_callback; called on each node expand.
Minimal Example
<div id="my-tree-container"></div>
<script>
  const treeData = [
    { name: 'Root', children: [
      { name: 'Child 1', children: [] },
      { name: 'Child 2', children: [] }
    ]}
  ];
  const tree = new uiframe.Tree({ name: 'my-tree', objects: treeData });
  tree.renderInto('my-tree-container');
</script>
