Dropdown

Minimal, searchable, animated menu

A compact dropdown with optional search, item animations, and event-driven selection.

Installation

Include the core and dropdown packages in your HTML: 

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">
<link rel="stylesheet" href="../packages/dropdown/dist/dropdown.css">

<!-- Scripts -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/dropdown/dist/dropdown.min.js"></script>
Quick Start
// Create and configure the dropdown
const dropdown = new uiframe.Dropdown({
  name: 'my-dropdown',
  options: {
    search: true,    // Enable search filter
    maxHeight: '15em' // Max height of item list
  }
});

// Render into a container
dropdown.renderInto('container-id');

// Add menu items
dropdown.setDropdownItems([
  { name: 'Option A', value: 'a' },
  { name: 'Option B', value: 'b' }
]);

// Listen for selections
dropdown.on('item:click', (item) => {
  console.log('Selected:', item.value);
});
Options
  • search: Enable search input filter (default: false).
  • maxHeight: CSS max-height for the item list (default: '15em').
API
  • renderInto(id): Renders the dropdown into the target container.
  • setDropdownItems(items): Populates the list. Expects array of { name, value } objects.
Events
  • item:click: Emitted when an item is selected. Callback receives the item object. 
    • dropdown.on('item:click', (item) => {
    console.log(item.name, item.value);
});
  • init: Emitted when the dropdown is opened for the first time (useful for lazy loading). 
    • // This will be helpful for lazy loading
dropdown.on("init", () => console.debug("[Demo1] Init fired (first open)"));
Features
  • Lazy loading: Use the init event to load items only when dropdown is first opened.
  • Search filtering: Enable search: true for auto-filtering as users type.
  • Separator items: Use null in the items array to create visual separators.
  • Item structure: Each item requires { name, value }; additional properties are preserved.
Minimal Example
<div id="my-dropdown"></div>
<script>
  const dropdown = new uiframe.Dropdown({ name: 'Pick' });
  dropdown.renderInto('my-dropdown');
  dropdown.setDropdownItems([
    { name: 'Option 1', value: 'opt1' },
    { name: 'Option 2', value: 'opt2' }
  ]);
</script>
