Split

Resizable panes layout

Two- or multi-pane layout with a draggable divider.

Installation

Include the core and split packages in your HTML:

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">
<link rel="stylesheet" href="../packages/split/dist/split.css">

<!-- Scripts -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/split/dist/split.min.js"></script>
Quick Start
// Create content for each pane
const topPane = document.createElement('div');
topPane.innerHTML = '<h3>Top Pane</h3><p>Your content here</p>';

const bottomPane = document.createElement('div');
bottomPane.innerHTML = '<h3>Bottom Pane</h3><p>More content here</p>';

// Create and configure the split pane
const split = new uiframe.SplitPane({
  containerID: 'split-container',
  top: topPane,
  bottom: bottomPane,
  options: {
    min_size: 100,      // Minimum pane size in pixels
    topHeight: '49.9%'  // Initial top pane height
  }
});

// Render the split layout
split.render();
Options
  • containerID: ID of the host element.
  • top: HTMLElement for the top pane.
  • bottom: HTMLElement for the bottom pane.
  • options.min_size: Min size in px for panes (default: 60).
  • options.topHeight: Initial top pane height (default: '49.9%').
API
  • render(): Renders the split layout into the container.
  • init(): Re-initializes event listeners (internal).
Events

This component does not currently emit custom events. Use CSS resize observers or manual drag tracking for advanced use cases.

Features
  • Fixed container height: The split container needs explicit height (in px or %).
  • Min size constraints: Set min_size to prevent panes from collapsing too small.
  • Dynamic content: Update pane content by modifying the DOM elements directly.
  • Two-pane only: Currently designed for top/bottom split layout.
Minimal Example
<div id="split-container" style="height: 500px;"></div>
<script>
  const top = document.createElement('div');
  top.textContent = 'Top area';
  const bottom = document.createElement('div');
  bottom.textContent = 'Bottom area';
  
  const split = new uiframe.SplitPane({
    containerID: 'split-container',
    top: top,
    bottom: bottom
  });
  split.render();
</script>
