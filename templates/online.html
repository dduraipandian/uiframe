Online

Network status indicator with optional toast notifications
Installation

Include the core and online packages in your HTML: 

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">

<!-- Scripts -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/online/dist/online.min.js"></script>
Quick Start
// Create the online status indicator
const status = new uiframe.Online({ 
  name: 'net-status',
  options: {
    notify: true,                    // Show toast on status change
    online_text: 'Online',            // Text when connected
    offline_text: 'Offline',          // Text when disconnected
    disappear_after: 3000             // Toast duration in ms
  }
});

// Render into a container
status.renderInto('status-container');
Options
  • notify: Show toast notification on status change (default: true).
  • online_text: Text to show when online (default: 'Online.').
  • offline_text: Text to show when offline (default: 'Offline.').
  • disapear_after: Toast duration in ms (default: 3000).
API
  • renderInto(id): Renders the status indicator (green/red dot + text).
  • updateStatus(): Manually checks and updates status (automatically called on clear events).
Events

This component automatically listens to window.ononline and window.onoffline events. 

// Status changes trigger internal updates and notifications
window.addEventListener('online', () => {
  console.log('Connection restored');
});
window.addEventListener('offline', () => {
  console.log('Connection lost');
});
Features
  • Automatic updates: No manual polling needed; uses native browser events.
  • Toast notifications: Enable with notify: true to alert users of status changes.
  • Minimal footprint: Only renders a status badge, no heavy UI.
Minimal Example
<div id="status"></div>
<script>
