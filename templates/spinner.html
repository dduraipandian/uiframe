Spinner

Minimal, configurable loading overlay

Overlay any container with a Bootstrap-spinner and optional progress text. Simple API, tiny footprint.

Installation

Include the core package in your HTML: 

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">

<!-- Scripts -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/spinner/dist/spinner.min.js"></script>
Quick Start
// Create the spinner component
const spinner = new uiframe.Spinner({
  name: 'my-spinner',
  options: {
    spinnerColor: 'text-primary',   // Bootstrap text color
    spinnerType: 'border',          // 'border' or 'grow'
    loadingText: 'Loading...',
    enableCancel: false             // Show cancel button
  }
});

// Render into a container
spinner.renderInto('container-id');

// Show the spinner with custom message
spinner.show('Processing your request...', true);

// Hide spinner when done
setTimeout(() => spinner.hide(), 3000);
Options
  • spinnerColor: Bootstrap text color class (default: text-secondary).
  • spinnerType:
    • border (default)
      Loading...
    • grow
      Loading...
  • loadingText: Default text to display (default: 'Loading').
  • enabledCancel: Show a cancel button (default: false).
API
  • renderInto(id): Renders the component into the target container.
  • show(text?, dotAnimation?): Shows the spinner. Optional text override and dot animation boolean.
  • hide(): Hides the spinner and re-enables the parent container.
Events

Listen to events on the container based on the pattern `spinner:{containerId}:{name}:cancel`. 

// Example: Handle cancellation
spinner.container.addEventListener(`spinner:${spinner.containerId}:${spinner.id}:cancel`, (e) => {
    console.log('User clicked cancel', e.detail);
});
Features
  • Parent state: Parent container gets disabled attribute while spinner is visible.
  • Progress text: Pass text to show(); enable dot animation with true parameter.
  • Cleanup: hide() clears timers and restores parent state automatically.
  • Custom colors: Use any Bootstrap text color class for styling (e.g., text-danger, text-success).
