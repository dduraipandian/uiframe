Tab

Simple, configurable tabs

Create tabbed views with a minimal API.

Install & Import

Use as an ES module.

<!-- Load core and tab packages -->
<link rel="stylesheet" href="../packages/core/dist/base.css">
<link rel="stylesheet" href="../packages/tab/dist/tab.css">
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/tab/dist/tab.min.js"></script>
Quick Start
const tab = new uiframe.Tab({ 
  name: 'my-tabs',
  options: {
    activeTab: 'home' 
  }
});
tab.renderInto('container-id');
tab.addTab({ id: 'home', title: 'Home', content: 'Home Content' });
tab.addTab({ id: 'profile', title: 'Profile', content: 'Profile Content' });
Options
  • tabs: Initial array of tab objects (optional).
  • activeTab: ID of the tab to show initially.
API
  • renderInto(id): Renders the tab layout into the target container.
  • addTab(tab): Adds a new tab. Expects { id, title, content }. Content can be a string, HTMLElement, or Component instance.
Events

This component relies on native Bootstrap tab events on the DOM elements. 

// Listen to Bootstrap tab show event
const tabElement = document.getElementById('tab-demo');
tabElement.addEventListener('shown.bs.tab', (event) => {
  console.log('Tab changed to:', event.target);
});
Features
  • Content flexibility: Pass strings, HTML elements, or Component instances as content.
  • Dynamic tabs: Use addTab() to add tabs after initialization.
  • Bootstrap integration: All tabs leverage Bootstrap's tab component utilities.
Minimal Example
<div id="my-tabs"></div>
<script>
  const tabs = new uiframe.Tab({ name: 'Simple' });
  tabs.renderInto('my-tabs');
  tabs.addTab({ id: 'tab1', title: 'Tab 1', content: 'Content here' });
  tabs.addTab({ id: 'tab2', title: 'Tab 2', content: 'More content' });
</script>
