Context Menu

Small context menu built on top of Bootstrap dropdown
Installation

Extends the Dropdown component. Include all required packages:

<!-- Styles -->
<link rel="stylesheet" href="../packages/core/dist/base.css">
<link rel="stylesheet" href="../packages/dropdown/dist/dropdown.css">

<!-- Scripts (order matters) -->
<script src="../packages/core/dist/core.min.js"></script>
<script src="../packages/dropdown/dist/dropdown.min.js"></script>
<script src="../packages/contextmenu/dist/contextmenu.min.js"></script>
Quick Start
// Create the context menu
const menu = new uiframe.ContextMenu({ 
  name: 'My Context Menu' 
});

// Render into a container
menu.renderInto('container-id');

// Define menu items
menu.setDropdownItems([
    { name: "Refresh", value: "refresh" },
    { name: "Rename", value: "rename" },
    { name: "Delete", value: "delete" },
    null, // separator will be created
    { name: "Properties", value: "props" },
]);

// Attach to elements for right-click menu
document.getElementById('target').addEventListener('contextmenu', (e) => {
  menu.show(null, e);
});

// Handle selections
menu.on('item:click', (item) => {
  console.log('Menu action:', item.value);
});
Options
  • maxHeight: Max menu height (inherited from Dropdown).
  • search: Enable search (inherited from Dropdown).
API
  • renderInto(id): Renders the menu hidden in the container.
  • setDropdownItems(items): Sets menu items. Items can have an optional callback property.
  • show(context, event): Shows the menu at the cursor position. Note: Target element or parent must have class context-menu-container.
  • hide(): Hides the menu.
Events
  • item:click: Emitted when an item is clicked (inherited from Dropdown). 
menu.on('item:click', (item) => {
  console.log('Menu item clicked:', item.name, item.value);
});
Features
  • Container requirement: Target or parent element must have class context-menu-container.
  • Separator items: Use null to create visual separators between groups.
  • Reusable menus: One menu instance can be attached to multiple targets.
  • Manual positioning: The show(context, event) method positions the menu at cursor.
Minimal Example
<div id="target" class="context-menu-container">Right-click me</div>
<div id="menu-holder"></div>
<script>
  const menu = new uiframe.ContextMenu({ name: 'ctx' });
  menu.renderInto('menu-holder');
  menu.setDropdownItems([
    { name: "Refresh", value: "refresh" },
    { name: "Rename", value: "rename" },
    { name: "Delete", value: "delete" },
    null, // separator will be created
    { name: "Properties", value: "props" },
  ]);
  document.getElementById('target').addEventListener('contextmenu', (e) => {
    menu.show(null, e);
  });
  menu.on('item:click', (item) => {
    console.log('Menu action:', item.value);
  });
</script>
